# Py Task Tracker

## Requirements

- Type: CLI

- Task Status (enum)
  - To-do
  - In Progress
  - Done
- Priority (enum)
  - Critical
  - High
  - Medium
  - Low
- Manage tasks
  - Create tasks
  - Read tasks
  - Update tasks
  - Delete tasks

- Task object
  - id (auto gen)
  - task name
  - task description
  - created date (default current)
  - updated date (default current)
  - status (string enum)
  - priority (string enum)
